# Base Subscription
A rescile base subscription represents a foundational module for a hybrid cloud and enables core security, networking, and governance controls for workloads that are deployed accross multiple cloud providers. It contains the Organization Structure, IAM Identity Center Integration, SCPs for Geofencing and Data Residency. Organizations use this as a template to spin up a cloud landing zone with a standardized baseline to ensure consistency across environments.
